## Summary

Replace the vectors and matrices starter template with a step-by-step NumPy lesson, and add a computer-vision lesson that trains the same CNN on CPU and CUDA. Learners can follow worked examples, complete exercises, monitor training with tqdm, and inspect a final performance report.

- Add vector arithmetic, shapes, broadcasting, dot products, a vector diagram, and a prediction mini project with exercise solutions.
- Train a CNN on the bundled handwritten-digits dataset with matching initial weights and batch order across devices, synchronized timing, warm-up, and repeated trials.
- Display training time, throughput, loss, held-out accuracy, GPU memory, charts, and predictions, with optional CSV/JSON exports and explicit CUDA skip/failure reporting.
- Include installation instructions and resource links. Keep CUDA dependencies specific to the lesson; the base Poetry configuration is unchanged.

## Validation

- Executed the vectors notebook in a fresh kernel and checked its exercise solutions.
- Executed the full CNN notebook on CPU and NVIDIA RTX 5070; saved measured outputs.
- Across three five-epoch trials, median training time was 0.770 s on CPU and 0.286 s on CUDA (2.69× speedup), with 94.17% held-out accuracy on both. These results apply to this small workload and recorded environment.
- Checked CPU-only reporting, simulated CUDA failure handling, and CSV/JSON exports.
- Ruff lint and formatting checks passed for both notebooks.
